# Character Builder

Roll a First Edition character one step at a time: each roll lands on the character sheet as you go, and at the end you can change anything on it, then print it or save it as a PDF.

The steps follow [Character Creation](/first-edition/cairn-srd/#character-creation) in the SRD. If you would rather have a whole character in one click, use the [Character Generator](/first-edition/tools/character-generator/).
